⚠️ Catatan Keamanan Sistem (Tantangan Pengembangan)

Aplikasi ini menggunakan localStorage hanya untuk kebutuhan simulasi. Pada pemilihan resmi, penggunaan localStorage sangat tidak aman karena:

  • Mudah Dimanipulasi: Pengguna dapat membuka Inspect Element / DevTools di browser dan mengubah angka suara atau menghapus status "sudah memilih" secara manual.
  • Penyimpanan Lokal (Client-Side): Data hanya tersimpan di satu browser/perangkat saja, tidak terpusat di server/database sehingga tidak bisa merekap suara dari banyak pemilih secara nyata.
  • Tidak Ada Autentikasi: Tidak ada verifikasi identitas pemilih (seperti NISN/token unik), sehingga satu orang bisa melakukan vote berulang kali dengan mode Incognito atau ganti browser.
